Who is actually out there

13 of the 15 busiest fingerprints run from more than one address

What they brought with them

Four file transfers, and one of them was empty

Two visitors uploaded a file called sshd over SFTP — a backdoor wearing the name of the service it replaces. One of them has the SHA-256 of a zero-byte file: the program uploaded nothing at all and carried on as though it had worked.

Limits

What this cannot tell you

  • One sensor, one address, a few days. This is what arrived at a single machine in one cloud region. It is not a measurement of the internet, and a second sensor elsewhere would see a different crowd.
  • A honeypot is detectable. Cowrie emulates a shell; anything careful enough to notice would leave without showing its hand, so the most capable visitors are the ones least likely to appear here.
  • Accepting almost any password shapes what is measured. The credential lists are real, but the number of successful logins says more about the trap than about the attackers.
  • Fingerprints group tools, not people. Two operators running the same off-the-shelf scanner share a hassh. The clusters are programs; who runs them is outside this data.
  • No malware family is named. Strings such as echo xsec are widely reported as bot markers, but that has not been verified here against a sample, so the programs stay unnamed.
  • My own testing is removed. 48 events from my own address were excluded by the query before any figure on this page was computed.
Method

How to check any number here

A Cowrie SSH honeypot runs on its own VM in its own network, and ships its logs one way to a ClickHouse instance. Every figure on this page comes from one snapshot file and one analysis file, both generated by script and both committed: the page is rendered from those files, never from a live query, so what was published can be reproduced and diffed against the next run. Two builds of the same window produce identical bytes.

Before any figure is computed, traffic from my own addresses and from private ranges is dropped in the query itself. The finished files are then scanned for anything that should never be published, and the build fails rather than writes. 1 attacker-supplied string mentioned the sensor's own address — a scanner that announces its target in its SSH version string — and was rewritten to a label rather than dropped, so the finding survives without the address.
